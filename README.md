En este repo esta contenida una app que pemite administrar las solicitudes de empleo enviadas.

Esto se realiza utilizando el metodo kanban que nos permite organizar distintas cards de acuerdo al estado de la tarea.

La pagina corre completamente de forma local valiendose de el almacenamiento en localstorage para guardar los datos de los estados de las solicitudes o CV.

Proximamente se buscara una manera de poder permitir que la pagina lea correos y pueda filtrar los correos de los remitentes que nos puedan interesar usando la informacion de las solicitudes, estos correos importantes apaeceran en el icono de notificaciones.
